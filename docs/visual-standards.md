# Visual standards: reputable neuroscience vs AI slop

## Reputable visual patterns

### EEG / BCI / neurophysiology

- Multi-panel raster + LFP traces with labeled channels and scale bars
- Spectrogram (time × frequency, perceptually uniform colormap e.g. viridis)
- Raincloud plots (raw data + distribution + box, one group = one color)
- Leave-one-subject-out error bars or subject-level lines over group means
- Receiver operating characteristic with bootstrapped CI band

### Scientific Python documentation style

- Clean white background, one accent color, ticks inward
- `figsize` matched to column width (3.4" single, 6.8" double)
- No chartjunk: no gridlines unless they aid reading, no 3-D effects

---

## Slop detector

A figure is slop if any of the following are true:

| Signal | Why it fails |
|---|---|
| Smoothly perfect "experimental" curves | Invented — no real experiment is that clean |
| Rainbow colormap (jet/hsv) | Perceptually non-monotone, colorblind-unfriendly |
| 3-D bar or pie chart | Distorts perception, never justified |
| Text rendered over data | Unreadable, lazy |
| Missing axis labels or units | Unscientific |
| Multiple accent colors | Dilutes emphasis, looks designed by committee |
| AI-generated art (dalle, midjourney, etc.) | Not reproducible, not data |
| Results not traceable to a script + data file | Cannot be verified |

## Kahlus figure rule

Every figure must satisfy:

1. **Source**: generated by a Python script from real data or real geometry
2. **Palette**: `#e8e8e8` (fill), `#bdbdbd` (secondary), `#8c1515` (accent, ≤ 2× per figure)
3. **Font**: Times New Roman or STIXGeneral, 9 pt, no text over data
4. **Axes**: labeled with units, ticks inward, linewidth 0.8
5. **Caption**: `Figure N.  Bold label followed by a full sentence.`
6. **Save**: `dpi=200`, `bbox_inches="tight"`, `facecolor="white"`
7. **Commit**: the PNG is committed to git alongside the script that generated it

If a figure cannot be generated from a script (e.g. a photograph), it must be:
- A CC-licensed external image
- Cited in the caption with author, source, and license
- Never cropped or altered in a way that changes scientific meaning
