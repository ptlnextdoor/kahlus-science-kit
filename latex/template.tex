\textbf{Abstract.}
This template demonstrates every structural element of the Kahlus LaTeX house style:
title block, abstract, numbered sections, a figure with a caption, a booktabs table,
and a reference list. Compile twice with \texttt{pdflatex} to resolve page counts.

\rule{\textwidth}{0.4pt}

\section{Purpose}

This document is a minimal shell. Replace the content of each section with your own.
The preamble sets Times New Roman, inward ticks (when using \texttt{pgfplots}),
booktabs rules, \texttt{siunitx} for units, and the standard header/footer.

Key rules:
\begin{itemize}
  \item One accent color per figure (\texttt{\#8c1515} in Matplotlib, or dark red in TikZ).
  \item No text over data.
  \item Every axis has a label and a unit.
  \item Claim gate in the pipeline diagram is always accented.
\end{itemize}
